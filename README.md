# Kubernetes Cert Manager Webhook for Spaceship.com

Cert Manager Webhook for Spaceship.com is an [ACME webhook solver](https://cert-manager.io/docs/configuration/acme/dns01/webhook/) for [cert-manager](https://cert-manager.io/) that enables the use of DNS01 challenges with [Spaceship.com](https://spaceship.com/) as the DNS provider, via the [Spaceship.com API](https://docs.spaceship.dev/#section/Spaceship-API).
